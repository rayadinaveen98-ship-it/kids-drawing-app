# 05 — Content Architecture

## Content dimensions

Each lesson should be tagged by:
- age bands
- difficulty
- category
- estimated duration
- target skills
- required tools
- teaching modes supported
- coloring support
- prerequisite/related lessons

## Initial category universe

Foundations, shapes, patterns, everyday objects, food, toys, vehicles, nature, flowers/plants, pets, wild animals, birds, insects, ocean life, dinosaurs, people, faces, expressions, clothing, buildings, landscapes, space, robots, fantasy, characters, comics, culture/folk-art inspired content, seasonal/festival art.

## Journey examples

- Animal Artist
- Character Creator
- Space Artist
- Nature Explorer
- Vehicle Designer
- Color Explorer

## Lesson package direction

A lesson should be data/content, not hard-coded application logic. Expected package elements include metadata, teacher stroke data, coloring regions/steps where applicable, narration keys/assets, hints and preview art.
