# 01 — Product Requirements Document (PRD) v0.1

## Problem

Children who want to learn drawing often face one of three experiences:
1. passive videos that do not wait for them;
2. simplistic tracing/coloring apps that do not truly teach;
3. professional drawing tools that are too complex for their age.

This product bridges those gaps with an interactive teacher, progressive art tools and a structured curriculum.

## Target users

Primary: children approximately 4–12 years old.  
Secondary: parents/guardians managing settings, progress and exports.

### Experience bands
- 4–5: Little Artists
- 6–7: Creative Explorers
- 8–9: Growing Artists
- 10–12: Young Artists

Age bands are policy/content metadata, not hard engine restrictions.

## Primary jobs-to-be-done

Child:
- Teach me how to draw something I care about.
- Go at my pace.
- Help when I am stuck without making me feel bad.
- Let me color my work.
- Let me create anything freely when I don't want a lesson.
- Let me see and feel proud of my past art.

Parent:
- Give my child a safe creative activity.
- Make the product understandable without constant parent assistance.
- Let me control privacy, exports and future purchases.
- Show meaningful learning progress without manipulative engagement mechanics.

## Core V1 flow

First launch → nickname → age → learning style → pace → interests → home → recommended lesson → guided drawing → optional help → coloring → completion → gallery.

## Must Have — V1

### Onboarding
- Child nickname
- Age / age band
- Guided mode preference
- Pace preference
- Interest selection
- Basic handedness option

### Home
- Age-appropriate recommendations
- Continue lesson
- Categories
- Art Journeys entry point
- Free Draw entry point
- Gallery entry point

### Guided Drawing
- Teacher stroke animation
- Draw With Me mode
- Watch Then Draw mode
- Trace & Learn mode
- Extra Slow / Slow / Normal / Fast / Very Fast
- Pause/resume
- Replay step
- Skip step where pedagogically acceptable
- Child drawing input
- Gentle hints
- Adaptive Help Ladder

### Coloring
- Continue from completed line art
- Guided coloring
- Self coloring
- Age-appropriate palettes/tools
- Undo/redo

### Free Draw
- Pencil
- Crayon
- Marker / basic brush
- Eraser
- Color selection
- Brush size
- Undo/redo
- Clear with confirmation
- Save artwork

### Companion
- Visible during appropriate lesson states
- Teaching, watching, encouraging, helping, waiting and celebrating states
- Voice/text feedback from controlled scripts/events
- Must never obstruct critical canvas content

### Gallery
- Auto/manual save as appropriate
- Artwork thumbnail grid
- Open artwork
- Basic metadata
- Parent-gated export

### Parent/Safety
- Parent gate for sensitive actions
- No public child profile
- No advertising identifiers in critical design
- No precise location
- No open child chat
- Minimal data model

## Should Have — V1 if quality permits

- Adaptive pace recommendation
- Draw-from-memory challenge
- Basic achievements based on skill/creation rather than streak pressure
- Offline lesson packs
- Multiple companion cosmetic expressions
- Basic accessibility accommodations
- Simple learning-progress insights for parents

## Later

- Story Drawing

- Additional companions

- Perspective guides
- Character design curriculum
- On-device voice commands
- Cloud backup/sync
- Parent accounts
- Cross-device profiles

## Explicit non-goals for early V1

- Social feed
- public comments/messages
- stranger collaboration
- mandatory login
- ads
- competitive leaderboards
- punitive accuracy scores
- unrestricted AI chatbot
- marketplace

## V1 success criteria

Product quality is achieved when:
- A new child can start a first drawing with minimal adult explanation.
- Teacher strokes feel responsive and understandable at every pace.
- Children can recover from mistakes without restarting.
- A complete drawing-to-coloring-to-gallery flow is reliable offline.
- Younger users are not overwhelmed by advanced tools.
- Core experience remains useful with no network connection.
- Test and performance quality gates are met on target Android hardware.
