## What changed

Phase 2 adds a production-grade structured Lesson Engine over the frozen Phase 1 Drawing Engine foundation:

- strict lesson package loading, validation and typed diagnostics;
- deterministic lesson session state machine and semantic snapshots;
- Draw With Me;
- Watch Then Draw full-lesson overview + child pass;
- Trace & Learn authored guide overlays;
- Help Ladder escalation/reduction/dismiss semantics;
- deterministic five-pace teacher playback: 0.4×, 0.7×, 1×, 1.5× and 2×;
- replay, pause/resume, valid/invalid skip handling and typed command rejection;
- versioned SHA-256 lesson-session persistence;
- child-document-first recovery;
- fresh runtime generations after recreation and stale-callback rejection;
- recoverable teacher playback failure + retry;
- post-drawing coloring handoff contracts and retryable handoff failure;
- real Lesson Lab integrating the actual Lesson Engine, Drawing Engine and bundled Cute Cat lesson;
- responsive physical-device Lesson Lab hotfix for portrait system insets/control layout.

## Frozen invariants retained

- UI does not own artwork/history/lesson truth.
- UI cannot set arbitrary lesson state.
- Teacher/trace/help overlays never enter child artwork history.
- Persistence stores editable operation data, not screenshots.
- AndroidX Ink stays behind drawing infrastructure boundaries.
- Core drawing/teaching remains offline.
- No ads, behavioral analytics, network dependency or sensitive permissions were introduced.
