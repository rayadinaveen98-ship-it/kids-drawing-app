# P2.5 Merge Gates

P2.5 must not merge merely because code compiles.

1. Store format is versioned and checksum-protected.
2. Primary/backup recovery is deterministic under injected corruption.
3. Child document restore precedes lesson-session restore.
4. Restore normalization is tested for overview, teacher playback, child turn, help active, drawing complete, and post-drawing states.
5. Stale playback callbacks are rejected after recreation.
6. Guide recreation remains outside child document/history.
7. All three teaching modes survive process recreation in deterministic tests.
8. Exact-head Android CI is green.
