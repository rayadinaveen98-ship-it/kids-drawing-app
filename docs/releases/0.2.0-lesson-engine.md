# Kids Drawing App — 0.2.0 Lesson Engine

Release date: **PENDING FINAL TAG**

## Purpose

`0.2.0-lesson-engine` is the second formal engineering milestone of the Kids Drawing App. It proves the structured Lesson Engine on top of the frozen Drawing Engine using the real bundled Cute Cat lesson, all three teaching modes, all five teaching paces, authored Help/Trace overlays, lifecycle-safe session recovery, and strict child-artwork isolation.

This is an **internal engineering milestone**, not the public child-facing V1 product.

## Proven implementation scope

- strict runtime loading/validation of bundled structured lesson packages;
- immutable lesson/session state owned by `LessonSessionEngine` rather than Compose;
- all three modes: Draw With Me, Watch Then Draw, Trace & Learn;
- all five frozen paces: 0.4× / 0.7× / 1× / 1.5× / 2×;
- teacher playback request/complete/failure handshake;
- Watch Then Draw full overview, Pause/Resume/Skip, then child drawing pass;
- replay-on-demand during valid child turns;
- authored Help Ladder with missing-level skipping, Reduce Help and Dismiss Help;
- Trace & Learn base trace guides plus Help overlays;
- teacher/trace/help strokes remain `TEACHER_GENERATED` and cannot enter child artwork history;
- app-owned versioned LessonSessionSnapshot codec and atomic primary/backup/temp session store;
- safe autosave at semantic lesson boundaries and app background;
- child-document-first process recreation;
- exact lesson revision compatibility checks;
- runtime-generation request IDs preventing stale pre-recreation callbacks from advancing restored sessions;
- safe teacher/overview restart after recreation;
- preserved help/trace guide rehydration;
- recoverable teacher failure → Retry with a fresh playback request;
- drawing-complete post-choice contract and safe coloring-handoff failure normalization;
- child artwork returned through incompatible/missing lesson recovery paths rather than stranded;
- dedicated Lesson Lab using the same production engine/controller boundaries, not mock session state.

## Milestone limitations

- Lesson Lab is an engineering interface, not production child-facing UX.
- No complete onboarding/Home/Learn/Create/Gallery product shell yet.
- Cute Cat is the reference engineering lesson; broad production content library comes later.
- Coloring Engine 0.4 is not implemented yet; Lesson Engine only proves the typed handoff/retry contract.
- No production companion animation/voice integration yet.
- No adaptive learning logic yet.
- No cloud/account requirement; core teaching remains offline-first.
- stylus-specific pending hardware coverage from `0.1.0-art-lab` remains separate and is not silently marked PASS here.
