# 03 — UX Architecture (Initial)

## Child mode primary destinations

- Home / Studio Lobby
- Learn / Explore
- Art Journeys
- Free Draw
- Gallery
- Profile/Companion lightweight entry

## Parent mode

Separated behind a parent gate:
- child profile settings
- safety/privacy
- exports
- future purchases/subscription
- content downloads
- progress insights

## Drawing lesson workspace

Priority order:
1. Canvas
2. current teaching action
3. companion feedback
4. essential controls
5. secondary tools only when requested

The interface should reduce chrome during active drawing.
