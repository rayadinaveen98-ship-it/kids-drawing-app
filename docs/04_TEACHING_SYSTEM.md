# 04 — Teaching System

## Teaching modes

### Draw With Me
Teacher demonstrates one stroke or small group of strokes, then waits for the child.

### Watch Then Draw
Teacher completes a larger step before the child attempts it.

### Trace & Learn
Guided path is visible initially; assistance fades as competence improves.

## Pace modes

- Extra Slow
- Slow
- Normal
- Fast
- Very Fast
- Adaptive / Match My Speed (later/should-have)

Pace affects animation duration, between-stroke pauses and explanation density—not lesson geometry.

## Adaptive Help Ladder

1. Independent attempt
2. Gentle verbal/visual hint
3. Faint guide
4. Anchor points/direction cue
5. Trace path
6. Assisted success

Goal: preserve momentum and confidence rather than mark failure.

## Feedback language

Avoid: Wrong, failed, bad, 42% accurate.  
Prefer: encouragement, specific observation, optional retry, help offer, creative variation acknowledgement.
